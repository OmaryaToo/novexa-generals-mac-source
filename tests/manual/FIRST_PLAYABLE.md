# Manual checklist — first playable (requires your own game files)

Record date, macOS, chip and result (PASS/FAIL/NOT RUN) for each line.

- [ ] Launcher opens; Diagnostics shows "Launcher architecture: arm64" and engine "[arm64]"
- [ ] Zero Hour folder selected; status "Installation verified" or "Usable"
- [ ] PLAY → state goes Preparing → Loading → Running
- [ ] Game window appears (windowed 1600×900), no black screen
- [ ] Main menu renders; music plays; mouse cursor tracks correctly on Retina
- [ ] Skirmish → choose map → AI opponent → Start
- [ ] Map loads; terrain, units and structures render
- [ ] Select units, issue move/attack orders; build a structure
- [ ] AI builds and attacks
- [ ] Sound effects and unit voices play
- [ ] Exit via in-game menu → launcher returns to Idle; no audio continues
- [ ] STOP button terminates a running game; launcher returns to Idle
- [ ] Fullscreen mode enters and exits cleanly (Cmd+Tab / quit)
- [ ] Launch log in Logs/ contains engine output
- [ ] Repeat for Generals
